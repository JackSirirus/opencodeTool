同一个按钮，图标随状态变化：完整态 ⤡（chevron-down，缩小）；紧凑态 ⤢（chevron-up，放大）。

按钮位置不变（刷新左侧），图标随窗口状态切换

切换
  • 缩小：main.setBounds() 以当前窗口右下角为不动点重算，300×400 → 300×120；图标 ⤡ → ⤢。
  • 放大：setBounds(300×400)，右 / 下边缘保持；图标 ⤢ → ⤡。
  • tab 状态在完整态与紧凑态之间共享：在完整态切到 Go 后缩小，紧凑态仍是 Go。
  • 切换为瞬时（无过渡动画），内容即时替换；resizable:false 只禁用户拖拽，不禁程序化 setBounds。

反馈规范

本模块不引入 toast（现有 widget 无 toast 体系）。反馈 = 顶栏圆点语义 + 条件状态标签 + 就地数值替换 + 刷新旋转。

(a) 顶栏圆点颜色语义

圆点含义触发条件动画
amber（默认）正常数据可用、无异常2.4s ease-in-out pulse
red限流任一额度窗口 status = rate-limited无（停止 pulse）
gray降级额度离线 / 无订阅 / 本地离线无

(b) 条件顶栏状态标签（hover 出完整文案）

标签出现条件hover 完整文案（title）
限流额度窗口 rate-limitedGo 已达 {窗口}上限 · 重置后自动恢复 · 期间可切免费模型（opencode/*）
额度离线额度 API 网络 / 超时失败无法连接 opencode.ai · 检查网络后点 ↻ 重试
无订阅无 opencode-go 凭据 / 订阅过期auth.json 中无 opencode-go 凭据，或订阅已过期
本地离线本地数据库不可用数据库不可用，等待中…（每 30s 重试）
限流Go 已达 {窗口}上限 · 重置后自动恢复 · 期间可切免费模型（opencode/*）
额度离线无法连接 opencode.ai · 检查网络后点 ↻ 重试
无订阅auth.json 中无 opencode-go 凭据，或订阅已过期
本地离线数据库不可用，等待中…（每 30s 重试）

(c) 刷新反馈：图标旋转 420ms

点击 ↻ → 添加 .is-spinning，transform:rotate(360deg)，transition 420ms ease；结束移除。

(d) 数值就地替换（不触发窗口缩放）

$1.23→$1.30 同一 DOM 文本节点更新；不调用 setBounds，窗口尺寸与位置保持不变。

交互行为规则表

触发 → 用户操作 → 系统行为 → 反馈。

触发用户操作系统行为反馈
缩小按钮（完整态） 点击顶栏 ⤡ main.setBounds(compact rect anchored bottom-right) 窗口 300×400→300×120；图标 ⤡→⤢
放大按钮（紧凑态） 点击顶栏 ⤢ setBounds(300×400) 图标 ⤢→⤡
紧凑态点击 费用 / Go 点击 pill tab 切换 pane（窗口尺寸不变，不移动） 内容即时替换
完整态切到 Go 后点击缩小 先点 Go，再点 ⤡ 紧凑态显示 Go（tab 状态共享） 缩小后仍是 Go 视图
拖拽顶栏（两种态） 按住顶栏拖动 移动窗口，尺寸不变 位置更新，尺寸保持
紧凑态点击刷新 点击 ↻ 拉取最新数据 图标旋转 420ms
紧凑态点击关闭 点击 ✕ 关闭窗口 窗口消失
数据推送到达（30s 费用 / 5min Go） 无操作 就地更新数值，窗口尺寸不变 数字就地刷新
额度变为限流 无操作（轮询） 顶栏红点 + 标签「限流」+ Go 最紧张行变红 状态标签出现
缩放锚点越界 缩小 / 放大 x/y clamp 到 workArea，不越出屏幕 窗口贴边不越界
切换瞬间 点击切换 无过渡动画（瞬时），内容即时切换 不闪烁 / 不滑动

说明：紧凑态固定 300×120，所有状态变化均就地替换内容、不改变窗口尺寸；状态反馈统一走 顶栏圆点 + 条件标签（hover 出完整文案），本模块不引入 toast。
