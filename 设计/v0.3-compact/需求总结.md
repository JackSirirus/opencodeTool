# 需求总结 — OpenCode 用量小窗口·紧凑模式（compact）

> 版本 v0.3 · 2026-09-11 · 设计探索产出（PRD 阶段输入）
> 配套文件：`compact-设计稿.html`（完整态 + 紧凑态布局）、`compact-全状态设计参考.html`（异常态 / 边界 / 交互规则）

## 背景

桌面小窗口（300×400）常驻屏幕右下角，信息完整但占屏明显。用户日常多数时候只想"瞄一眼"今日费用或套餐额度，不需要图表、Top3 模型/项目等明细。需要一个更小的常驻形态，在不丢关键数字的前提下把窗口收成一条迷你面板。

## 目标

1. 给现有 widget 增加「缩小 / 放大」一键切换，在完整视图与紧凑视图间往返。
2. 紧凑态·费用视图 = 今日 / 本周 / 累计 费用三项。
3. 紧凑态·Go 视图 = 套餐额度（5 小时 / 本周 / 本月）。
4. 紧凑态仍可切换费用 / Go；两种视图尺寸一致，切换不跳动。

## 功能范围

### 做什么

- 顶栏新增「缩小 / 放大」切换按钮（同一按钮，图标随状态变化）
- 紧凑态窗口 ≈ 300×120，锚定右下角（左/上边缘内收）
- 紧凑态保留「费用 | Go」切换，tab 状态与完整态共享
- 紧凑态·费用：三行清单（今日 / 本周 / 累计，label 左、数值右）
- 紧凑态·Go：三行额度（5 小时 / 本周 / 本月，进度条 + 百分比 + 重置时间）

### 不做什么

- 不持久化缩小状态（原因：用户选择"每次完整视图"，零额外文件）
- 不做 hover 自动展开（原因：与拖拽 / 点击交互冲突）
- 不做多尺寸档 / 自由缩放（原因：需求只要求一档紧凑）
- 不做系统托盘 / 开机参数（原因：超出本版本范围）
- 不引入 toast（原因：现有 widget 无 toast 体系，反馈沿用 banner + 顶栏状态）

## 载体

已存在的 Electron 桌面小窗口（`src/widget/`）的一个新显示模式，不新增窗口 / 应用。入口 = 顶栏新增的缩小按钮。

## 关键决策

| # | 决策 | 原因 |
|---|------|------|
| 1 | 还原方式 = 同一按钮切换，图标在缩小 ⤡ / 放大 ⤢ 间变化 | 最直观，用户确认 |
| 2 | 紧凑态保留费用 / Go 切换 | 两个视图都要能看，用户确认 |
| 3 | 信息全、一眼读清（不砍信息） | 用户确认的密度取向 |
| 4 | 不持久化缩小状态，重启回完整视图 | 用户确认；零额外文件 |
| 5 | 缩放锚定右下角（左 / 上边缘内收） | 贴合屏幕角，视觉稳定，用户确认 |
| 6 | 紧凑态统一尺寸 300×120（两视图同尺寸） | 避免切 tab 时窗口抖动 |
| 7 | 布局方案 A：三行清单（label 左、值右）；Go 行 = 进度条 + % + 重置 | 从 7 个 ASCII 方案中选定；可读性最高、最接近现有 `.go-qrow` 结构 |
| 8 | 视觉沿用现有 dark glass tokens，新增类加 `compact-` 前缀 | 与现有 widget 一致，无新设计规范 |
| 9 | 缩小按钮置于刷新左侧（`⤢ ↻ ✕`），加 `-webkit-app-region: no-drag` | 顶栏是拖拽区，按钮必须退出拖拽 |
| 10 | tab 状态在完整 / 紧凑间共享 | 缩小后看到的即缩小前的视图，符合预期 |
| 11 | 紧凑态隐藏独立 banner，状态压缩为顶栏圆点 + 条件小标签（限流 / 额度离线 / 无订阅 / 本地离线），hover 出完整文案 | 固定高度不抖动；信息仍可获取 |
| 12 | 实现：新增 IPC `setCompact(bool)`，main 用 `setBounds` 重算右下角锚点；不改现有 5 个桥方法签名 | v0.2 护栏 G3 要求只增量新增 |
| 13 | 保留 `resizable:false`，程序化 `setBounds` 改尺寸 | 该选项只禁用户拖拽，不禁程序化 |
| 14 | 模块名 `compact`，版本 v0.3 | 用户确认 |

## 技术约束

- 现有窗口：`BrowserWindow` 300×400、`resizable:false`、`alwaysOnTop('screen-saver')`、右下角锚定 `EDGE_MARGIN=16`；常量位于 `src/widget/main.js`
- 缩放锚点算法：以当前窗口右下角为不动点，`x = right - newW`、`y = bottom - newH`，并 clamp 到 `workArea`
- 顶栏 `.card__header` 是 `-webkit-app-region: drag`，新按钮必须 `no-drag`
- CSP `default-src 'self'; script-src 'self'`，禁内联脚本，所有逻辑进 `renderer.js`
- 现有 `window.widget` 5 个桥方法签名不可改，只增量新增（`preload` 暴露方法 + 主进程 IPC）
- 零依赖：不新增 npm 包；本次不引入持久化
- 复用现有 `styles.css` tokens 与 `.go-qrow` 结构：
  - 颜色：`--amber #f5b942`（费用）、`--violet #c4b5fd`（额度）、`--cyan #7ed3ff`（命中率）、`--danger #ff6b6b`、`--warn #fbbf24`
  - 圆角 `--r-sm/md/lg = 6/10/14px`；等宽字体 `--mono`，UI 字体 `--ui`
- 紧凑态不显示独立 banner（见决策 11），固定 300×120 不抖动
