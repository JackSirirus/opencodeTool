# 需求总结 — OpenCode Go 套餐用量查看（go-usage）

> 版本 v0.2 · 2026-09-07 · 设计探索产出（PRD 阶段输入）
> 配套文件：`go-usage-设计稿.html`（正常态布局）、`go-usage-全状态设计参考.html`（异常态/边界/交互规则）

## 背景

opencodeTool 现有显示工具（CLI + 桌面小窗口）以"费用"为主指标，但主力 provider `opencode-go` 是 $10/月订阅套餐，按美元额度限流（5h $12 / 周 $30 / 月 $60），费用数字不反映套餐健康度。用户需要看：请求量、用过哪些模型、各模型请求分布、缓存命中率、以及**套餐剩余额度**。

## 目标

新增 Go 套餐专用视图：CLI 子命令 `usage go`（完整版）+ 桌面小窗口 Go Tab（精简版），双数据源 = 本地 SQLite（用量统计）+ OpenCode 官方 API（服务端额度）。

## 功能范围

**做什么**
- CLI `usage go`：今日/本周/累计三档（请求数、tokens、费用标记）+ 套餐额度三窗口（5h/周/月）+ 缓存命中率双口径（今日+累计）+ 模型全表（请求量降序，--sort cost 可选）+ 近 7 天表 + `--json`
- 小窗口 Go Tab：今日请求 hero + 额度三条 + 命中率双条 + 本周/累计行 + 模型 Top3 + footer（读写占比 + CLI 指引）
- 套餐额度：调 `GET https://opencode.ai/zen/go/v1/usage`（Bearer key，key 读自 auth.json `opencode-go.key`）

**不做什么**
- 不换算"剩余美元/剩余请求数"（API 只返回 percent；限额按模型乘数分配，换算必然失真）
- 不标注 DeepSeek 峰谷价（复杂度不值，文档已存档）
- 不做 Zen 余额查询（官方无 API，issue #10448 仍 open）
- 不做其他 provider（opencode 免费模型）的同视图——数据同源但口径独立，免费模型仅在 rate-limited 提示中作为出路出现

## 技术约束

### 数据源 1：本地（已验证）
- `opencode.db` 只读（node:sqlite readOnly，WAL 安全）；口径 providerID=opencode-go
- 请求 = assistant message 行数；tokens 从 message.data JSON（input/output/reasoning/cache.read/cache.write/total）
- 命中率：占输入 = cacheRead/(input+cacheRead+cacheWrite)；读写占比 = cacheRead/(cacheRead+cacheWrite)
- 费用标记 = message.data.cost 累计（订阅套餐下是"美元价值标记"非实际扣费，UI 措辞用"费用标记"）

### 数据源 2：官方额度 API（已实测 200）
- `GET https://opencode.ai/zen/go/v1/usage`，Header `Authorization: Bearer <key>`
- key 位置：`~/.local/share/opencode/auth.json → opencode-go.key`
- 响应：`{usage: {rolling|weekly|monthly: {status: "ok"|"rate-limited", percent: 0-100, resetsAt: ISO}}}`
- 错误：401 AuthError（key 无效）；403 EntitlementError（无 Go 订阅）
- 限额规则（docs/go/，2026-09-07 版）：$10/月订阅；5h $12 / 周 $30 / 月 $60（美元价值计价）；每个模型有独立月额度乘数（$15~$100）；超限后开 "Use balance" 回退 Zen 余额，否则阻止；免费模型始终可用
- 实现：Node 内置 fetch（保持零依赖）

### 数据基线（2026-09-07 快照，用于测试对照）
- 累计：26,991 请求 / 12 模型 / 6.41B tok / $168.99 / 命中 97.39% / 99.96%
- 今日：268 请求 / 24.1M tok / $1.44 / 命中 86.9%；本周：1,558 / 331.3M / $13.25
- 额度实测：rolling 7% / weekly 2% / monthly 42%
- 验收口径：独立 SQL 交叉核对（本表数字仅作开发对照，禁冻结断言）

### 复用与加固现状
- widget 已完成 preload.cjs + contextIsolation 加固；Go Tab 走 window.widget 桥接，新增 `quota:update` 推送通道与 `usage:refresh` 一致模式
- 数据层新增 `getGoUsage()`（零依赖，从不抛异常，available 契约与 getUsageSummary 一致）
